About this page

"Active" means a request from that user in the last 15 minutes; the timestamp itself updates at most once a minute per user.

Errors below are anything ERROR/CRITICAL/WARNING the application logger emitted -- including unhandled exceptions, which are recorded here before the user sees the error page, so this list should be checked first when something appeared to crash.

The detailed request log covers every request (not just errors) but lives on disk, not here, since its volume would dwarf every other table.
