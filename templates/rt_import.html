Import tickets

Every RT ticket that hasn't already been imported becomes a new incident: RT Queue maps to an assignment team (matched by name, or created if none matches — same as CSV CMDB import resolves team names), RT Requestor/Owner map to ServiceOps users by email (auto-created if not found), RT Status/Priority map to the closest ServiceOps equivalent, and the ticket's correspondence and file attachments come across too. A ticket already imported (matched by its RT ticket ID) is always skipped, never duplicated — safe to re-run after fixing a mapping problem. Run a preview first and check the sample rows below before applying anything. RT is not modified in any way — this only reads from it.
